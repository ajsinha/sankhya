# What the venv holds, pinned.
#
# Only the deck needs a third-party package. Everything else this repository runs in Python ---
# `tools/mutation-audit.py`, the Python SDK, the parity soak, the TLS binding test --- imports
# the standard library and nothing else, which is deliberate and worth keeping: an SDK that
# needs a wheel to open a socket is an SDK somebody cannot try in five minutes.
#
# Pinned rather than floored, for the reason `rust-toolchain.toml` pins the compiler: a version
# that renders a slide differently on one machine turns the deck into a property of whoever
# built it. Refresh with `.venv/bin/pip freeze > requirements.txt` when a bump is intended.
